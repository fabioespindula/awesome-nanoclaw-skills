# Identity Shuffle

Use identity shuffle only when multiagent or swarm execution is available and a second pass will improve the answer.

The goal is to reduce role anchoring. Advisors should critique anonymized substance, not names or personalities.

## Advisor Names

- The Skeptic
- The Thesis
- The Market
- The Customer
- The Operator

## Shuffle Rules

1. Strip advisor names from first-pass outputs.
2. Preserve the substance of each view.
3. Randomize order if the runtime makes that easy.
4. Ask advisors to critique the set without knowing which role wrote which point.
5. Reattach advisor names only for the final synthesis.

## Output To Keep

Keep only the critique that changes the final recommendation:

- missed risk;
- stronger opportunity;
- bad assumption;
- better sequencing;
- customer reality check.
