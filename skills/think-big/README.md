# Think Big

`think-big` opens a broad possibility space without becoming vague.

It maps signals, mechanisms, scenarios, second-order effects, risks, and opportunities around a market, product, technology, society, career, company, behavior, culture, or life theme.

## Use It

Primary command:

```txt
/think-big future of AI-first CRMs
```

Other examples:

```txt
/think-big pensar grande sobre marketplaces de agentes
/think-big What happens to checkout experiences when agents buy for users?
```

Aliases and trigger phrases:

```txt
think big
pensar grande
future of
where is this going
opportunity scan
```

## Behavior

- Uses disciplined imagination, not generic brainstorming.
- Separates facts, signals, inferences, and speculation.
- Prefers mechanisms over slogans.
- Challenges consensus when useful.
- Routes concrete decisions back toward a decision-review frame such as `rethink`.

## Output

The default output is a strategic exploration with:

- reframed theme
- strong and weak signals
- mechanisms driving change
- plausible scenarios
- opportunity and risk map
- useful provocations or experiments

## Requirements

NanoClaw runtime. Browser or research tools are useful when current sources matter.

## Install

```bash
rsync -a skills/think-big/ /path/to/nanoclaw/container/skills/think-big/
```

Or install it through `awesome-updater`:

```bash
python3 skills/awesome-updater/scripts/awesome_skills.py install think-big \
  --source-dir "$PWD" \
  --skills-dir /path/to/nanoclaw/container/skills
```
